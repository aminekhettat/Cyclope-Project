# Local model assets

No weights are bundled. Add the validated files described in the project README:

- yolo26s_float16.tflite (default)
- yolo26m_float16.tflite (optional)
- yolo26n_float16.tflite (optional)

Use pretrained COCO detection with 80 classes, float16 weights and float32 I/O.
Missing models are explained in the app. Never substitute depth or custom-class weights under these filenames.
