# Documentation

Cross-cutting documentation for the Cyclope project. One folder per work
package, mirroring the top-level layout of the repository.

| Folder | Holds |
|---|---|
| `Global/` | Documents covering the whole project: the presentation given to students, roadmaps, cross-package specifications |
| `01-Raspberry/` | Notes on the GEN 1 server |
| `02-Embedded/` | Meeting notes and specifications for the camera board and its firmware |
| `03-Vision/` | Dataset notes, training protocols, evaluation results |
| `04-3D_Design/` | Enclosure design notes, mass budget, print and assembly instructions |
| `05-Android_app/` | Application specifications, accessibility notes, user-facing behaviour |

`images/` holds the illustrations used by the root README.

Empty folders carry a `.gitkeep` file so that Git keeps them; delete it as
soon as the folder holds real content.
